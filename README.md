# 🧠 Artificial Intelligence Roadmap

> Complete roadmap covering Artificial Intelligence, Machine Learning, Deep Learning, Computer Vision, Generative AI, LLMs, RAG and AI Agents.

---

# 📚 About This Repository

This repository provides a structured learning path to understand the main concepts, algorithms, tools and applications of modern Artificial Intelligence.

The roadmap starts with the fundamentals of AI and Machine Learning and progresses towards Deep Learning, Computer Vision, Generative AI, Large Language Models (LLMs), RAG systems and AI Agents.
